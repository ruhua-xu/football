# Football System 0.5.0 Real Data Integration

当前 `0.4.0` 已通过验收。

现有能力包括：

* immutable AnalysisRun
* P_market / P_quant / P_final
* EV
* 简单 2串1
* Portfolio Optimizer
* CashPosition
* Exposure / Stress Test
* ANALYSIS_PACKET_V1/V2
* LLM_REVIEW_V1/V2
* FusionRun
* PortfolioRevision
* Historical Archive
* MatchResult
* Settlement
* Walk-forward Backtest
* Brier / LogLoss / Calibration
* ROI / Drawdown
* GitHub Actions CI

以上能力全部冻结。

本阶段进入：

**0.5.0 Real Data Integration**

本阶段核心目标不是增加更多模型，而是让现有系统第一次能够稳定读取真实足球数据，并完成：

1. 一次真实历史赛季的 `P_market` 回测。
2. 一次当天真实竞彩足球 AnalysisRun。
3. 导出真实 `ANALYSIS_PACKET_V2` 给网页 GPT。
4. 保持现有所有时间、审计和不可变规则。

---

# 一、总体原则

本阶段始终遵守：

```text
先保证真实数据正确
再讨论预测效果

先有来源
再有字段

先保存原始事实
再做标准化

不确定的数据显式缺失
不得由程序或 LLM 补造
```

本阶段禁止：

* LightGBM
* XGBoost
* CatBoost
* 神经网络
* Transformer
* 多 Agent
* 自动下注
* Web Dashboard
* 3串4
* 4串11
* 复式
* 自动参数搜索
* 大规模模型调参

不要修改已经冻结的 LLM Review V2 文件合同，除非发现无法兼容真实数据的阻断性 Schema 问题。

# 三、真实数据源先做研究，再接入

不要一开始绑定多个供应商。

先建立：

```text
fankui/real_data_source_review.md
```

对以下候选源进行实际调查和小样本验证。

## 候选 1：中国竞彩网 / 体育彩票官方来源

目标用途：

* 当天竞彩足球受注赛事
* sporttery_match_no
* 胜平负 SP
* 让球信息
* 销售状态
* 最终赛果

优先级最高，因为系统最终实际计算竞彩 EV 时需要中国竞彩固定奖金。

但必须首先确认：

* 是否存在稳定公开接口
* 页面数据结构
* robots / 服务条款 /公开使用边界
* 是否允许本地个人研究读取
* 是否允许保存历史快照
* 是否存在明确 API

如果无法确认稳定、合法、长期可维护的自动接口：

**不要强行写网页爬虫。**

改为实现：

```text
SportteryManualArchiveProvider
```

支持用户把当天竞彩网数据保存为标准 CSV/JSON 后导入。

真实每日分析可以接受：

```text
竞彩网人工导出
+
其他数据源自动获取
```

第一版不要求所有数据都自动化。

# 十六、真实 P_quant 第一版

当前 ManualQuantProvider 不能作为正式每日方案长期依赖。

但本阶段禁止复杂 ML。

请实现一个**简单、确定性、容易回测的 Quant Baseline**。

优先考虑：

```text
ELO_POISSON_BASELINE_V1
```

或如果实现成本明显过高：

```text
ELO_THREE_WAY_BASELINE_V1
```

要求：

* 不使用未来结果
* 状态随时间更新
* 不把 Team ID 直接当固定实力
* 赛季变化允许连续更新
* 参数全部版本化
* 可从历史结果重新构建
* 相同输入产生完全相同概率

模型至少输出：

```text
P_quant HOME
P_quant DRAW
P_quant AWAY
```

如果当前数据不足以计算可靠 P_quant：

系统必须允许：

```text
P_quant unavailable
```

不要复制 P_market 冒充 Quant。

# 十七、Elo 时间模型

如果选择 Elo：

每支球队拥有随时间变化的 rating。

比赛按时间顺序更新。

必须支持：

```text
initial_rating
K factor
home advantage
season transition
promoted team initialization
```

参数写配置。

赛季转换不要把球队永久固定成上赛季强弱。

可以实现可配置：

```text

```

例如向联赛平均水平回归。

具体值不要声称已经最优。

后续真实回测确定。

# 十八、不要立即训练参数
